# 07 六周学习计划

假设每天 1~1.5 小时、周末可多一点。每周有一个"可验证的产出"，做不出来就回退到对应文档。

学习原则：

- **先跑通，再理解，最后改造**。不要一上来读框架全部源码。
- 每个知识点都要在服务器上留下"我改过"的痕迹。
- 每周末用 30 分钟写 10 行笔记：这周最反直觉的一点是什么。

## 每天 45 分钟模板

```
10 min  回顾昨天的笔记 + 看今天的文档小节

```

不要追求"看完"，追求"改过"。
